Service

무엇을 만들 수 있고, 얼마나 걸리는가

제작 가능한 콘텐츠 11가지를 목적별로 정리했습니다. 유형마다 참여 흐름과 끝나고 남는 데이터를 같이 적었습니다. 목적과 시기만 알려주시면 어떤 유형이 맞는지부터 함께 정리합니다.

Step 1

목적을 먼저 고르면 유형이 좁혀집니다

인지형·판매형·데이터 확보형은 KPI가 다르고, 그래서 맞는 콘텐츠도 다릅니다. 세 가지를 한 캠페인에 담을 수는 있지만 1차 목적은 하나여야 합니다.

목적1차 KPI맞는 유형필요한 데이터 구조
브랜드 인지형
새 브랜드·신제품을 알린다		 참여율, 점유 체류시간 브랜드 미니게임, AR 필터, 포토부스, AI 이미지 변환 참여 로그 + 지점별 QR 구분
판매 연결형
현장·연계 채널에서 판다		 쿠폰 사용률, 구매 전환율 룰렛·즉시쿠폰, 인증 이벤트, 퀴즈 쿠폰 코드 ↔ 결제 데이터 매칭
데이터 확보형
다음 캠페인 자산을 만든다		 유효 동의 확보율, 명단 1건당 원가 유형 테스트, 포토부스, 스탬프 투어, 출석체크 참여 ID + 동의 대장 + CRM·CDP 이관

KPI를 잡는 방법은 가이드 01 — 팝업스토어 KPI, 목적별로 이렇게 잡습니다에서 더 자세히 다룹니다.

Step 2

제작 가능한 콘텐츠 11가지

모두 앱 설치 없이 QR 한 번으로 진입하는 웹 기반입니다. 유형마다 끝나고 무엇이 데이터로 남는지를 함께 적었습니다.

유형참여 흐름끝나고 남는 데이터주 목적 / 기간
A · 참여를 만드는 것CATCH
룰렛 · 럭키드로우현장 · 온라인 QR 스캔 → 룰렛 1회 → 즉시 쿠폰 발급 → 매장 사용 시 결제 매칭 참여 ID · 스캔 지점 · 당첨 등급 · 쿠폰 코드 · 사용 시각·매장 판매기본형 1~2주
퀴즈 · OX현장 · 온라인 진입 → 3~5문항 → 결과와 해설 → 보상 또는 공유 참여 ID · 문항별 정답률 · 완주 여부 · 소요 시간 인지 · 판매기본형 1~2주
유형 테스트현장 · 온라인 문항 6~10개 → 유형 판정 → 결과 카드 → 저장·전송(동의 지점) 참여 ID · 유형 결과 = 세그먼트 · 동의 항목 · 연락처 데이터기본형 1~2주

어떤 유형이든 기본으로 들어가는 것

  • 앱 설치 없이 QR 한 번으로 진입하는 웹 구조 — 설치를 요구하면 진입에서 대부분 이탈합니다
  • 참여 시점 방문객 ID 발급 — 이 키가 없으면 이후 어떤 측정도 성립하지 않습니다
  • 참여 로그 자동 수집 — 스캔 · 시작 · 단계 통과 · 완주 · 동의 · 보상 수령
  • 모바일 반응형과 실기기 QA — iOS Safari, Android Chrome, 카카오톡·인스타그램 인앱 브라우저
  • 종료 시 원본 로그와 세그먼트를 브랜드에 이관 — 리포트만 남기지 않습니다

Step 3

소요기간과 포함 범위

발주 검토와 품의에 그대로 쓰실 수 있게 포함·제외·추가 항목을 나눠 적었습니다.

구분소요기간포함해당 유형
기본형 1~2주
영업일 기준		 콘텐츠 1종 · 브랜드 스킨(색·로고·폰트) · 참여 로그 수집 · 결과 화면 · 모바일 반응형 · 기본 성과 리포트 룰렛, 퀴즈·OX, 유형 테스트, 인증 이벤트, 스탬프 투어, 출석체크, 추천코드
커스텀형 3~5주
영업일 기준		 기본형 전체 + 커스텀 게임 규칙·아트 · 랜딩 페이지 · 관리자 화면 · 참여자 명단 CSV · 랭킹·보상 관리 · 실시간 대시보드 브랜드 미니게임
AI·AR형 4~6주
영업일 기준		 커스텀형 전체 + AI·AR 구현 · 키오스크·포토부스 연동 · 현장 운영 대응 · 트래픽 대응 설계 AR 필터, 포토부스·키오스크, AI 이미지 변환

별도 견적으로 구분하는 추가 항목

  • 고급 일러스트·캐릭터 디자인, 사운드·BGM 제작
  • 다국어 대응
  • 외부 시스템 연동 — CRM · CDP · POS · MMP
  • 현장 운영 인력, 경품 사입·배송, 촬영·영상

업무 범위가 아닌 것 — 매체 집행(광고 지면 구매·운영)은 저희가 하지 않습니다. 필요하시면 대행사와 병행해 진행하고, 저희는 수집한 데이터를 타깃 모수로 넘기는 지점까지 맡습니다.

위 기간은 참고 범위입니다. 확정 일정과 포함·제외 기준은 요구사항 확인 후 견적서에 명시합니다. 캠페인 중간의 규칙 변경과 기능 추가는 기본 범위 밖입니다.
